Wardveil Security branding is governed by the unified GoreeCloud branding repository.

- Authority repository: `GoreeCloud/goreecloud-branding-assets`
- Canonical system path: `systems/wardveil-security/`
- Canonical icon: `systems/wardveil-security/wardveil-security-icon.svg`

- Canonical Git blob: `fb3d643cca5477c3f8d4e03ce10a3458fd12f407`

`branding/wardveil-security-icon.svg` is a synchronized consumer derivative retained only for packaging, deployment, validation, offline use, performance, and Wardveil-owned presentation needs. It is not an independent branding authority.

New Wardveil logos, icons, artwork, lockups, identity concepts, or revisions must originate and be approved in `GoreeCloud/goreecloud-branding-assets` first. After approval, required derivatives may be synchronized here and must remain traceable to the exact canonical source.

Branding identifies Wardveil Security but does not create or prove technical protection, malware detection, antivirus coverage, runtime acceptance, security posture, compliance, or production readiness. Those claims remain governed by Wardveil implementation and current authoritative evidence.
