# Security Center — Glaze UI 2.0.0 adoption

Security Center targets **Glaze UI 2.0.0 Stable** from `GoreeCloud/goreecloud-glaze-ui`, pinned to promotion revision `ff3fff4306bd53ea9c0715a7c0d64265bb038617`.

The deployed web subset contains only the Stable contracts exercised by Security Center: Soft Glaze material behavior, Appearance and Clarity state, Navigation Capsule focus/target semantics, 48 px interactive target floors, reduced-motion substitution, reduced-transparency solid fallback, increased-contrast handling, and forced-color fallback.

This adoption changes presentation only. Wardveil Security remains authoritative for security state and evidence. Glaze UI cannot create or strengthen a Protected claim.

Rendered/platform acceptance remains separate from source validation and must be evidenced before this site is used as proof of broader Glaze UI portfolio conformance.
