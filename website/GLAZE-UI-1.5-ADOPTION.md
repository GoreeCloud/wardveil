# Security Center — Glaze UI 1.5.0 adoption

The Security Center targets **Glaze UI 1.5.0 Stable** from `GoreeCloud/goreecloud-glaze-ui` revision `2c5078410d022eba683c8e029bc3cafe773df0b7`. Stable web layers are vendored into the deployment and mapped onto Wardveil Security surfaces, evidence/protection state presentation, focus, materials, and reduced-motion behavior. Candidate/Wearable layers are excluded.
